# スマートフォンの模擬試験一覧を縦開きへ変更

2026-11-01の依頼「スマホ版のサイドバーのアコーディオンは縦開きにしてください、世界史版と同じ感じで」に対応する。

参照は公開世界史版の画面のみ。他サービスのソース・資料・DBへは接続しない。ローカル世界史画面3200は停止していたため、既知の公開URLでSP390×844の開閉を確認した。ヘッダー直下の縦開き・2列の模試一覧・内部縦スクロール・非モーダル表示に合わせる。

## 変更内容

- `frontend/app/components/ExamSidebar.vue`：SPの模擬試験一覧をヘッダー直下の縦開きへ変更。世界史版と同じ2列・最大3段程度の高さと内部縦スクロール、大問の全幅表示、上下の矢印に揃えた。横からの全高パネル、背景幕、モーダル指定、本文スクロール固定、Tab循環を除去した。閉状態の操作抑止・Escapeで起動ボタンへ戻る動作・画面移動と幅変更時の閉鎖は保持する。
- `frontend/tests/examSidebarLayout.test.ts`：既存検査のSP横パネルへの期待を、縦開き・2列・非モーダルへ更新した。検査の新規追加はしていない。

開始前から存在したPCの「サイドバーを開く/閉じる」の文言変更を保持した。PCの260/64px開閉、公開教材カタログ・利用資格、教材/大問リンクは変更していない。他作業の未コミット変更は保持。DB更新・コミット・push・本番反映は今回の依頼範囲に含めない。

## 検査と現在地

既存レイアウト検査7件、開発コンテナの型検査、`git diff --check`、ローカル専用資料の追跡・履歴検査は成功。コードの独立レビューでは修正必須の指摘なし。世界史版の実操作で、ヘッダー直下absolute・2列・最大高さ209px・bodyスクロール固定なしを確認した。

ホストにはNuxt実行ファイルがないためホスト型検査は環境不足だった。停止中だったDockerと日本史専用の開発環境を起動し、コンテナ内の型検査で成功を確認した。教材のseedは行っていない。

Macのロックで実操作確認を一度保留し、ユーザーの解除連絡後に再開した。変更したソースは検査時のSHAと同一で、型検査・既存7件は繰り返さず、未確認だった画面操作を確認した。

### PC/SP実操作

ローカル `http://127.0.0.1:3300/` の実画面で14項目を確認し、すべて成功した。

- 390×844：ヘッダー直下に幅390px・高さ209pxの一覧を縦に展開。模試7件が2列で並び、本文のスクロール固定・モーダル・ページ横はみ出しなし。
- 一覧内を縦スクロールし、本文を動かさず末尾の模試7へ到達。模試6を開くと4大問が全幅366pxで表示され、実リンクを選んで `/practice/6/24` へ移動し、一覧が閉じる。
- 320×740：偶数列の模試6の4大問が左右12pxの内側・全幅296pxに収まり、長い題名も折り返す。内部スクロールで大問と末尾教材へ到達できる。
- Escapeで一覧を閉じ、起動ボタンへフォーカスを戻す。閉状態のTab移動は一覧内リンクへ入らない。開閉の反復ができ、開いたまま本文もスクロールできる。
- 760pxではスマホ用の全幅一覧、761pxではPCの260pxサイドバーへ切り替わる。切り替え時にスマホ側の開状態が閉じ、操作抑止がPCへ残らない。
- PCの閉じ操作でサイドバーと本文の左端が64pxへ同期。PCで閉じた後にスマホへ切り替えても、スマホの開操作とリンクが使える。1440pxでPCを開くと260pxへ同期し、横はみ出しなし。

操作画像6枚と `ui-results.json` を保存。確認終了時に一時的な画面サイズ指定を解除した。独立したコード・画像レビューの最終判定は `local-only/mobile-sidebar-vertical/final-review.json` に記録する。

安全な検査結果と開始前ソース、参照画像は `local-only/mobile-sidebar-vertical/` に保持する。
