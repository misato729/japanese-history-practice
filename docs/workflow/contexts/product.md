# 学習設計・サービスの方針

日本史の効率的学習を支援する演習サービス。日本史ラボは仮称です。教材のDB登録状況はstateと実DBで確認し、未分類を正式分類と扱いません。

正本は `config/exam.json` と実問題DB。仮分類を教科書分類、合成5問を教材と扱いません。課金・販売は無効、公開先・運営者情報は未設定です。

教材・大問・小問、共通本文、選択・短答・論述、章節と文化史4区分を維持します。論述採点規則の登録・検証状況はstateとローカル検証記録で確認します。

受領済みの過去問2年度・参考教科書・用語集はローカル専用です。分析は `分析/過去問分析.md` を入口とし、教科書の代表照合と `分析/用語集再分析/` の設問別照合を分けます。用語集の教科書掲載冊数は試験出題頻度・難易度とは区別し、語の存在と必要細部・解答経路を別に評価します。分析の仮分類・暫定難度・非公式推定配点はアプリの正式設定へ自動反映しません。

予想問題5セットの現行版は `local-only/predicted-exams-20261030-v3/README.md` が入口です。初稿は `local-only/predicted-exams-20261030/`、難度改訂版は `local-only/predicted-exams-20261030-v2/` に保持しています。各セット4大問30問、四択20・語句8・80字論述2で、問題冊子と解答・解説を分けています。難度の再検討では過去問60問・初稿150問・改訂版150問を最短解法と用語集の個別見出しで比較し、137問と本文20本を改稿しました。前版の全問の独立レビューと比較結果はv2の `reviews/` と `難度再検討.md` を参照します。

史料読解修正版では各セット2問、計10問の四択を変更し、史料の判断と独立した知識を組み合わせています。変更10問は作者と異なる担当者が原画像・全肢・最短解法を再確認し、残る140問は前版の内容と検証を継承しました。全150問の形式・参照・正答一意・語句露出・論述字数等の自動検査も通過しています。変更内容と限界はv3の `修正内容.md` と `reviews/` に記録しました。既知史料の内容を知識で代替できる場合があり、実測正答率・所要時間による同難度や公式採点を保証しません。作問タスクではDB登録・公開・教材の外部送信を行いません。後続の明示依頼で5セット150問をローカルDBへ登録した記録は、stateの `register_predicted_mock_sets` と `local-only/mock-db-import-20261030/` を参照します。

新課程用語を中心とする模試6・7は `local-only/new-curriculum-mocks-20261031/README.md` が入口です。14頁の全361項目を赤字解説の有無で限定せず原本参照し、個別見出し357項目と関連見出しまでの4項目、一覧原表記と原本の表記差を区別しました。各4大問30問、形式B/Aを継承し、全60問の構造検査・作者と別担当のレビュー・最短解法による再判定を完了しました。論述は80字、参考8点を2点×4または2・3・3点に分け、複数の許容文言を記録しています。資料は作問者の要約・自作表で、一次史料の原文読解負荷まで同等とはしません。難度・中心性・検証範囲は同フォルダの `検証結果.md`、変更区分は `変更ファイル一覧.md` を参照します。DB登録・外部送信・公開は行っていません。stateの `author_new_curriculum_mocks_6_7` に完了根拠を記録します。
