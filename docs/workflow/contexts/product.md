# 学習設計・サービスの方針

日本史の効率的学習を支援する演習サービス。日本史ラボは仮称で、実問題のDB登録・正式分類・対象試験の設定は今後決めます。

正本は `config/exam.json` と実問題DB。仮分類を教科書分類、合成5問を教材と扱いません。課金・販売は無効、公開先・運営者情報は未設定です。

教材・大問・小問、共通本文、選択・短答・論述、章節と文化史4区分を維持します。日本史の論述採点規則は未登録です。

受領済みの過去問2年度・参考教科書・用語集はローカル専用です。分析は `分析/過去問分析.md` を入口とし、教科書の代表照合と `分析/用語集再分析/` の設問別照合を分けます。用語集の教科書掲載冊数は試験出題頻度・難易度とは区別し、語の存在と必要細部・解答経路を別に評価します。分析の仮分類・暫定難度・非公式推定配点はアプリの正式設定へ自動反映しません。

予想問題5セットの現行版は `local-only/predicted-exams-20261030-v2/README.md` が入口です。初稿は `local-only/predicted-exams-20261030/` に保持しています。各セット4大問30問、四択20・語句8・80字論述2で、問題冊子と解答・解説を分けています。難度の再検討では過去問60問・初稿150問・改訂版150問を最短解法と用語集の個別見出しで比較し、137問と本文20本を改稿しました。全問の独立レビューと根拠は改訂版の `reviews/`、比較結果は `難度再検討.md` を参照します。知識要求の偏りは改善しましたが、史料の複数照合などの処理負荷には差が残ります。実測正答率による同難度や公式採点を保証せず、DB登録・公開・外部送信は行いません。現在地はstateの `recalibrate_mock_difficulty` を参照します。
