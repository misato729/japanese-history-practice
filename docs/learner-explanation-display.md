# 解答解説から作問用の内部評価を除外

確認日: 2026-11-01。ローカル画面への反映のみ。コミット・push・公開環境への反映は行っていない。

演習の解答解説に混入していた難度のK/P評価と、直後の最短解法・他問からの情報供給に関する作問レビューを表示から除外した。資料種別の内部識別子と重複する書名も表示しない。原典名と抜粋・省略・訓読・句読点・表記変更等の注記、通常の解説・各肢の説明・参考採点は保持する。

既存データには表示時の変換を適用し、保存済みの評価記録や回答履歴には変更を加えない。元の構造に一致する単純テキストの評価2ブロックだけを除外する。単独の見出しやID付きの文、引用等を語句の部分一致で削除しない。将来のローカル取り込みでも、作問評価を学習解説へ混ぜない。
