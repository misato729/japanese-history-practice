# 設定・教材更新

`config/exam.json` がサービス名・案内・分類・料金の正本です。現在は日本史ラボの仮名、仮の2章・各1節、教材番号5枠です。枠数は収録数ではありません。日本史の分類・出典を決めてから差し替えます。

`site.id` はCookieも識別します。小分類の `major_category_value` は実在する大分類へ対応させます。分類変更はDBの主分類・関連分類と整合させます。

文化史4区分は維持します。問題は単一の内訳、演習条件は複数区分をORで選べ、章節とはANDです。全区分で文化史全体、未選択なら文化史で絞りません。

教材・大問・小問は管理画面から下書き登録し、本文参照・正答・全肢・解説・出典・公開条件を確認して公開します。公開済み小問を別回答形式へ変える場合は新規登録します。

論述は `frontend/server/data/essay-rule-profiles.ts` に日本史用規則を追加してから使用します。字数・指定語・要素・関係の肯否・未知表現、モデルの全要素充足を検査します。規則変更時は旧版を保持し、新版を追加します。合成テスト規則を公開用に転用しません。

設定変更後は `node scripts/check-template.mjs` と再起動を行います。設定だけで既存問題DBは更新されません。通常編集でseedや再取込を使いません。

一回払い決済は保持しますが、`payments.enabled=false` と販売フラグfalseが初期値です。500円は未使用の仮値。販売開始には対象サービスのStripe設定・運営者情報・法務文言・決済確認と明示指示が必要です。
