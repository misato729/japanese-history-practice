# 全模試の論述許容表現と自動採点

2026-10-31の「全ての模試」の許容表現拡充と自動採点登録の依頼に対応しています。対象は模試1〜7の14論述・48採点要素です。各要素に12例以上、合計584例の自然な許容文言を用意しました。文言・答案・原典画像・採点規則の実データはローカル専用です。

## 実装と登録

- 完全な関係文の許容例、読点の違い、指定語の併記異表記を扱います。複数事実で1要素になる場合は、主体・対象が独立して確認できる各節を組み合わせます。暗黙の主体が必要な既知答案は全文完全一致だけで補完します。
- 否定、仮定、撤回、主客の逆転、必要事項の欠落、単語列挙、正誤併記を検査します。未知の文言は保留とし、論述の履歴の正誤はnullです。無制限の自然言語理解や公式得点は保証しません。
- 旧10規則の第1版を保持し、模試1〜5は第2版へ、模試6・7の4論述は第1版へ登録しました。カタログは24版、実際に使用する規則は14件です。エンジンは `literal-rules-v3`、各問題は規則版とdigestを固定します。
- 専用のローカルDBへ共通Writer・単一トランザクションで反映しました。既存10論述の採点設定を更新し、新しい2セット・8大問・60問を追加しました。合計7セット・210問（選択140、語句56、論述14）です。起動時の自動投入は行いません。
