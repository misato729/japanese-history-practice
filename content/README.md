# 合成テスト用データ

`questions.json` は表示・保存・採点・アーカイブの検査用5問です。書籍・過去問を使用せず、文字列が一致する選択肢を選ぶ合成データで、日本史の教材ではありません。

入力・公開検査のためJSON内は1セット5問・公開扱いを満たしますが、通常起動ではDBへ投入しません。実問題は管理画面から登録します。

`db:seed` は開発環境で明示実行した場合だけ空の問題DBへ合成5問を登録する互換操作です。共有環境・実問題の更新には使用しません。本番では実行されません。

`source_text` の `example.invalid` は、旧形式のHTTPS出典欄を検査するための予約ドメインで、実在する参考資料へのリンクではありません。
